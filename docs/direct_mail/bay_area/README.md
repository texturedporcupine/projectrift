# SF Bay Area Shared Postcard Direct Mail Launch Kit

This folder contains Bay Area-adapted deliverables generated from
`sf_directmail_cursor_brief.pdf`.

The original brief referenced Austin/Texas source assets that are not present in
this repository, so these files provide clean Bay Area source materials that can
be used directly or copied into deck/document generators.

## Recommended first campaign

Start with Danville, CA 94526. Confirm 2-3 EDDM carrier routes totaling roughly
5,000-7,000 households, then build a 30-40 business prospect list across
non-competing categories before outreach.

## Operating assumptions

- Shared postcard format: one exclusive advertiser per business category.
- Target delivery size: 5,000-8,000 households.
- EDDM postage: `$0.247` per piece, paid at Destination Delivery Unit drop-off.
- Payment terms: 50% deposit at signing, 50% before print.
- Bay Area pricing defaults:
  - Tier 1: `$700-900` standard, `$1,100-1,400` premium placement.
  - Tier 2: `$550-750` standard, `$850-1,100` premium placement.
  - Tier 3: `$400-600` standard, `$650-850` premium placement.
