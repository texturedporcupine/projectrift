# Creative Brief — Shared Postcard (Market Neutral)

Use this for designers and printers. Replace bracketed fields per campaign.

## Campaign

- **Market / community:** `[e.g., Danville, CA 94526]`
- **Mail date target:** `[date]`
- **Format:** `[8.5" x 11" OR 6.5" x 9"]` flat, **14pt+** cardstock, EDDM flat specs
- **Quantity:** `[5,000–8,000]` (match EDDM bundle)

## Brand & voice

- **Headline tone:** Local, trustworthy, “neighborhood services” — no gimmicky stock phrases
- **Required legal:** Advertiser-provided disclaimers where regulated (medical, dental, contractor license #s if required)

## Layout

- **Address side:** EDDM indicia **upper right**; return address block per printer spec
- **Ad blocks:** One business per category; no competing categories on same card
- **Bleed / safe zone:** Per printer template

## Deliverables

- Print-ready PDF with fonts outlined or embedded
- Proof approvals: **email approval** from each advertiser before print
