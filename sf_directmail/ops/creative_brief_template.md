## DESIGNER SPECIFICATIONS

| Spec | Requirement |
|------|-------------|
| File format | Press-ready PDF (CMYK) |
| Resolution | 300 DPI minimum |
| Color mode | CMYK |
| Bleed | 0.125" on all sides |
| Safe zone | 0.25" from all trim edges |
| EDDM indicia | Upper-right corner, address side (see indicia template) |
| Address area | Bottom 3.5" of address side must remain clear |
| Postcard size (8.5"×11") | 8.75" × 11.25" with bleed |
| Postcard size (6.5"×9") | 6.75" × 9.25" with bleed |

### EDDM Indicia Text (place exactly as shown)

2. Publisher forwards to advertiser contact listed above
3. Advertiser must respond in writing (email) within **3 business days**
4. Up to **2 rounds of revisions** included
5. Additional revisions: $50/round (invoice separately)
6. No response within 3 days = deemed approved per service agreement
