# Pitch scripts — by category

Use these as **phone or in-person scripts** after the 3-email outreach sequence
has earned a callback. Each follows the same structure:

1. **Open** — 10-15 seconds. Warm, local, specific. Establishes you are not a
   call-center.
2. **Hook** — One concrete reason this category wins on this campaign.
3. **The offer** — What they get. Exclusivity. Pricing range.
4. **Pre-objection** — The thing they're about to say, said before they do.
5. **Ask** — A clean, narrow ask. Either "10 minutes Thursday?" or
   "Want me to email the one-pager?".

If they raise an objection mid-script, **switch immediately** to
`sales/objection_handler.md`.
